REDEX PLAN — Static website

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a modern browser, or upload the entire redex-plan-site folder to a static host (GitHub Pages, Netlify, Vercel, etc.).
3. Keep the assets folder beside index.html.

FEATURES
- Responsive Arabic-first website with REDEX PLAN branding.
- Seven-day training schedule based on the supplied reference images.
- Interactive exercise checkboxes and weekly progress tracker saved in the browser's localStorage.
- Rest, nutrition, and safe-training guidance.

NOTE
This is a front-end static site. It does not include user accounts, cloud sync, or a server/database. The exercise plan is adapted with beginner-friendly ranges and safety notes; adjust it to your experience and get qualified supervision for challenging skills.
